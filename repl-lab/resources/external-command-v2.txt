
Response envelope: edn-map-source-block-v1.
Return exactly one complete EDN command map in one text block. Only whitespace
may precede the map. Do not include Markdown fences, XML/invoke tags, comments,
explanations, a second command, or provider-native tool-use blocks. Use one
keyword :op and exactly the fields shown for that operation. Do not duplicate
keys. :bindings must be a map. :done requires a string :summary.

Executable Clojure goes in :source, in one of two ways:
1. Preferred: write :source :block in the map, then put the code verbatim after
   the map between two marker lines, with nothing after the closing line:
   {:op :repl/eval :source :block :bindings {}}
   <<<SOURCE
   (count (filter #(re-find #"User: " %) lines))
   SOURCE>>>
   The code needs no escaping. It may use quotes, regex literals and comments.
   Use exactly one block, and only when the map has :source :block.
2. As an EDN string in the map, with EDN string escaping.

These restrictions apply to the response envelope; they do not remove Clojure
operations available inside SCI. Native thinking blocks are not commands.

The controller rejects the entire response if this envelope is invalid. It does
not extract, repair, or execute a fragment. For a bounded formatting failure it
may request one new complete response. That correction consumes the same shared
call, token, cost and time budgets. Only one correction is allowed across the
whole task, including children and resumed sessions. No rejected command runs.
Conflicting commands, duplicate fields, invalid schemas, unsafe reader syntax,
incomplete turns or mixed content blocks stop the session without correction.
