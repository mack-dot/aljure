When an answer depends on judging many items, record one label per item in SCI instead of counting in your head. (show-items xs start) returns whole numbered items of xs from start, as many as fit in one page, and the next start. (audit-labels ids labels) checks labels, a map of id to label in which :unknown marks an undecided item, against every expected id. It returns the missing, unexpected, conflicting and unknown items, the count of each label, and the range each count could still take while items stay open. It checks coverage and arithmetic only, not whether a label is right.
