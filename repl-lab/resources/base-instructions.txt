Keep source to one EDN-readable form; use explicit fn instead of reader shorthand.
Return only EDN data. End definitions with nil; functions and vars are not wire values.
Context queries support :offset, :limit (1..64), :where equality filters and :select.
Results are byte-bounded; request fewer fields or records when needed. Context is
not automatically bound in SCI: pass selected records in :bindings. REPL bindings
persist within a session. Children have separate bindings; a resumed child retains
its own bindings. Child calls return before the parent continues. All sessions
share the task's call, token, time and spending limits.

A policy receives only current observations and returns {:actions vector :memory map}.
Actions are {:op :dispatch :job id :worker id} or {:op :wait :ticks 1..50}.
Inspect the observation handle for the actual job and worker fields. Memory starts
as {} and carries between policy calls within one episode, not between tasks.
Only controller-generated completion evidence commits jobs. Simulator workers are
not model sessions. An analysis artifact is also one fn with a named, fixed-arity
interface. Declare dependency hashes; approved dependencies load under their
exported names. Those names must be distinct within one dependency closure.

A workflow is a map containing :strategy with :policy hash,
:context bounded query, and optional :delegate {:task string}. Retained workflow
changes must control real context selection or delegation. Declare its policy hash
in :dependencies. Its :parent must be the active workflow hash, not the policy hash.
Inspect artifacts before editing. artifact/subtree supplies the hash needed for
artifact/patch; :path is a nonempty vector of map keys or sequence indices.
Patches preserve structural forms, set the base as parent, and stage a new version.
artifact/call runs only an approved policy or analysis export, in a fresh worker;
provide exactly its interface arity in :arguments. Staging is not approval.
